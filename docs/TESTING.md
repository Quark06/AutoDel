## 本地功能演示（Local Demo）

运行 `npm run dev`，打开 http://localhost:5173/ 。

1. 选择 3 秒，聊天 A 中点击悬浮按钮，确认高亮。
2. 在 A 发送消息，确认约 3 秒后消失。
3. 切换聊天 B，确认开关关闭，发送消息后等待 3 秒，消息仍在。
4. 切回 A，确认开关保持激活。
5. 在 A 发消息后立刻关闭，确认该消息仍按原定时间删除，关闭后发送的消息保留。
6. 在 A 激活、选择 10 秒发送消息，再改成 3 秒发另一条；确认分别按自己的延时删除。

`npm test` 提供可重复的核心功能检查；`npm run build` 后还有构建产物的加载和卸载检查。
