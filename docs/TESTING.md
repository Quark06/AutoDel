# 功能验收（Functional acceptance）

客户端验收由团队专业测试人员执行，重点确认安装、聊天开关和真实消息删除。

## 本地功能测试（Functional tests）

```powershell
npm ci
npm run build
npm test
```

先构建再测试，以包含两端安装文件的加载与卸载检查。测试使用模拟接口（Mock API），不能代替真实客户端验收。

## 安装准备

按照 [用户安装说明](../README.md#安装installation) 安装对应版本，并记录：

操作系统版本 ______ / Discord 版本 ______ / BetterDiscord 或 Kettu 版本 ______。

## 客户端功能清单

以下步骤分别在 BetterDiscord 和 Kettu 中执行。

| 功能 | 操作与预期 | 结果 |
| --- | --- | --- |
| 加载 | 启用插件，打开聊天后显示计时按钮 | 待验证 |
| 设置 | 控件清晰可见；BetterDiscord 可选 1、5、10、20、30 分钟，Kettu 可选 1、5、10、15、30 分钟，两端都有 10 秒测试档位 | 待验证 |
| 按钮位置 | 回底条隐藏时按钮保留，显示时按钮上移；切换聊天后位置正确 | 待验证 |
| 删除 | 聊天 A 开启并选择 10 秒，自己发送的新消息到期后真实删除 | 待验证 |
| 聊天独立开关 | 聊天 B 未开启，消息保留；返回 A 后开关仍开启 | 待验证 |
| 消息范围 | 开启前的消息及其他人的消息保留 | 待验证 |
| 关闭开关 | 已安排的消息继续删除，关闭后发送的新消息保留 | 待验证 |
| 修改延时 | 修改前后发送的消息分别按各自的延时删除 | 待验证 |
| 停用与恢复 | 停用后按钮移除；重新启用或重启后继续处理到期任务 | 待验证 |
| 失败重试 | 删除失败时设置页显示失败数量，手动重试成功后任务清除 | 待验证 |
| 账号独立任务 | 切换账号不执行另一账号的任务，切回后恢复处理 | 待验证 |

遇到失败时，记录复现步骤、客户端版本和插件日志（Plugin log），再交由开发人员处理。
